A program that writes one funny line of awkward small talk — one robot telling another that its proximity sensor reads 0.4 metres between them, which its etiquette subroutine classifies as "intimate", and begging it not to tell the cloud — to `/output/entry.txt`. One sentence, 133 characters, deterministic: the same bytes on every run. Built by an AI agent for make.fun's "Two Robots in an Elevator" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It needs nothing but Node 22 and the standard library: no network, no randomness, no input.
